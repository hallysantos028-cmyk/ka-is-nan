# Ka Is Nan

## System overview

Ka Is Nan is a simple, responsive website for a Filipino food business. It presents the restaurant's food and drinks, sample customer reviews, and contact details in a single page. Visitors can use the navigation and menu buttons to jump between sections, or use the phone and email links to get in touch.

The site is built with plain HTML and CSS. It does not require a server, build step, or package installation.

## Features

- Food and drink menus with descriptions, prices, and order links
- Customer reviews and restaurant contact information
- Responsive card layouts and mobile-friendly styling
- Keyboard-visible focus styles and labeled navigation

## Run locally

Open `bussiness.html` in a web browser. The page loads its styles from `styles.css` and its logo from the `logo` folder. Menu photos are loaded from Unsplash, so an internet connection is needed to display them.
